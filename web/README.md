# web —— 医生数据智能助理前端

Vue 3 + Vite + TypeScript，无 UI 框架依赖。三块界面（§14-11 / §18.4.6）：

| 页面 | 路径 | 说明 |
| :-- | :-- | :-- |
| 登录页 | `/login` | 口令登录，失败只显示统一措辞（不区分原因，防账号探测，§4.5） |
| 对话页 | `/` | SSE 流式对话：步骤卡 / 技能卡 / 工具卡 / 文件卡 / 确认按钮 / 澄清选项 / 流式文本 / 最终答案 |
| 管理页 | `/admin/*` | M2 角色授权、M3 技能包、M4 接口注册、M5 口径字典、M6 审计 |

## 跑起来

```bash
npm install
npm run dev          # http://127.0.0.1:5173，开发服务器把 /v1/* 代理到下面两个后端
npm run typecheck    # vue-tsc
npm run build        # 产出 dist/（生产由 nginx.conf 托管）
```

开发代理目标可用环境变量覆盖（默认值只是本机骨架期的端口）：

```bash
VITE_AGENT_SERVICE=http://127.0.0.1:8081 VITE_MANAGEMENT_SERVICE=http://127.0.0.1:8082 npm run dev
```

两个后端都要在跑：`agent-service`（:8081，对话与 SSE）与 `management-service`（:8082，登录与管理）。
两边的 JWT 密钥必须是同一个（`*_JWT_SECRET`），否则登录拿到的令牌在对话页会被判 401。

## 三个必须遵守的前端口径

**令牌不进 URL。** 发消息是 `POST /v1/agent/sessions/{id}/turns`（令牌走 `Authorization` 头），
换回来的是一次性入场券；只有**券**允许出现在 SSE 的 query 里（§19.4）。

**一次性券 + 换券重连。** 券核销即失效，浏览器 `EventSource` 的原生自动重连会拿旧券撞 401，
所以 `src/lib/sse.ts` 自己接管重连：断开后调 `POST /v1/agent/sessions/{id}/tickets` 换一张新券，
并带上最后收到的 `seq`（`afterSeq`），服务端只补没看过的那一段——刷新页面不丢答案，也不重播。

**审计查询必须带时间范围。** `src/lib/time.ts` 在发请求前就校验「左闭右开 + 单次 ≤31 天 + UTC」，
服务端同样会拦（§20.5）；默认窗口是近 24 小时。

## 两个「停止」的分工（别混）

| 按钮 | 在哪 | 按下去发生什么 |
| :-- | :-- | :-- |
| **停止接收** | 流状态行旁边 | 只断开这条 SSE：服务端继续生成，点「重新连接」回来接着看（§19.4 断线续传） |
| **停止生成** | 生成时**发送键的位置**变成的方形键 | **服务端真的取消这一轮**：会话还在、已产出的内容保留，停完可以马上问下一轮 |

「已停止」这个结论由服务端在收尾事件里说清楚（`done` 带 `stopped=true`，见后端 `SseProjector`），
前端归约器（`src/lib/turn.ts`）据此把这一轮定稿 —— 不去猜「停止接口的响应」和「这条事件」谁先到：
两者顺序不确定，猜错就会把一份**已经收好的答案**显示成「已停止」。接口响应只兜一种底：流已经断了、
收不到那条事件时，用它标记这一轮。
