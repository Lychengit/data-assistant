# 报表列与来源

| 列 | 来源接口字段 | 说明 |
| -- | -- | -- |
| 医生编号 | `doctor_id` | 跨月不变，可回查 |
| 医生姓名 | `doctor_name` | 以接口返回为准，不用名单页的显示名 |
| 科室 | `dept_code` | 中文科室名（如实照搬，不做翻译） |
| 统计月份 | `stat_month` | `YYYY-MM`，与入参 `month` 一致 |
| 指标 | `metric_key` | 与入参一致；口径说明写在第二张表 |
| 指标值 | `metric_value` | 数值原样落表，不做四舍五入（精度由口径字典 `rounding` 决定） |
| 单位 | 口径字典 `unit` | 门诊人次=人次；药占比=0~1 的小数（0.31 即 31%） |

## 为什么列是这几列

导出字段清单的**上界**来自绑定接口的返回字段契约（`sys_api.result_schema`），
不是另配一份白名单。所以这份报表只能出现在上面这些字段里——
绩效类数据发布时要在 M3 里审的就是这份清单。
